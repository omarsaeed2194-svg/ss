# إعلانات فيديو — عرض اللابتوب (شنطة Jeep كروس + ستاند لابتوب)

٣ إعلانات فيديو لفيسبوك وإنستجرام، بفويس أوفر مصري وترجمة عربي ثابتة على الشاشة (أغلب الناس بتتفرج والصوت مقفول).

| الإعلان | المدة | الفكرة |
|---|---|---|
| `v1_main` | ~31 ثانية | الإعلان الأساسي: سؤال يشد ← العرض ← مميزات الشنطة ← الستاند ← بيتطبق ← اطلب |
| `v2_short` | ~15 ثانية | نسخة سريعة للريلز والستوري |
| `v3_gift` | ~21 ثانية | زاوية الهدية: "محتار تجيب هدية إيه؟" |

كل إعلان طالع بـ ٣ مقاسات:

| الملف | المقاس | يتحط فين |
|---|---|---|
| `*_9x16.mp4` | 1080×1920 | Reels و Stories (فيسبوك وإنستجرام) |
| `*_4x5.mp4` | 1080×1350 | الفيد (Feed) — الأفضل للفيد على الموبايل |
| `*_1x1.mp4` | 1080×1080 | الفيد و Marketplace و الـ Right column |

ومع كل إعلان: صورة غلاف `*_cover.jpg` وملف ترجمة `*.ar_AR.srt` (ممكن ترفعه في Ads Manager كـ captions).

## حاجات لازم تتأكد منها قبل ما تنشر

1. **الدفع عند الاستلام**: مكتوب على الشاشة في آخر كل فيديو. لو مش متاح غيّر `cash_on_delivery` لـ `false` في `ads.json` واعمل build تاني.
2. **اسم المتجر**: استخدمت "بيتي / Baity" (من اسم الدومين). لو الاسم مختلف غيّره في `ads.json`.
3. **السعر**: مش ظاهر لأني ماعرفتش أفتح صفحة المنتج. اكتب `price` (و`old_price` لو فيه خصم) في `ads.json` وهيظهر في مشهد "اطلب دلوقتي".
4. **الصوت**: الفويس أوفر الحالي معمول بصوت مُركّب أوفلاين (موديل عربي اتعدل نطقه للهجة المصرية). كويس كنسخة مبدئية، لكنه مش بجودة معلق صوتي حقيقي، وترخيص استخدامه التجاري مش واضح. قبل ما تصرف فلوس على الإعلان، اعمله تاني بصوت مصري احترافي (الخطوات تحت) أو سجّل صوت حقيقي.
5. **اسم Jeep**: فيسبوك ممكن يرفض الإعلان لو اسم الماركة مستخدم في منتج مش أصلي من الشركة. لو حصل رفض، شيل كلمة Jeep من `ads.json`.

## إعادة الإنتاج / التعديل

المتطلبات: Python 3.10+ و ffmpeg.

```bash
pip install numpy scipy pillow onnxruntime edge-tts
python3 build.py                               # كل الإعلانات بكل المقاسات (الصوت الأوفلاين)
python3 build.py --ads v2_short --formats 9x16 # إعلان ومقاس واحد
```

**صوت مصري احترافي** (أصوات Microsoft المصرية: شاكر للصوت الرجالي، سلمى للصوت الحريمي):

```bash
python3 build.py --tts edge                             # شاكر
python3 build.py --tts edge --voice ar-EG-SalmaNeural   # سلمى
# أو بحساب Azure Speech مدفوع ومرخّص تجارياً:
AZURE_SPEECH_KEY=... AZURE_SPEECH_REGION=... python3 build.py --tts azure
```

كل النصوص في `ads.json`:
- `text`: الجملة اللي بتظهر على الشاشة (وهي اللي الصوت المصري الاحترافي بيقراها).
- `say`: (اختياري) لو عاوز الصوت يقول حاجة مختلفة عن المكتوب، زي "جيب" بدل "Jeep".
- `franco`: نفس الجملة بالفرانكو المصري، دي اللي الصوت الأوفلاين بيقراها (`2`=ء، `3`=ع، `7`=ح، `kh`=خ، `sh`=ش، والحروف الكابيتال `S T D Z` = ص ط ض ظ).
- `title`: العنوان الكبير فوق في كل مشهد.

## الملفات

- `build.py` — المونتاج كله: الصوت، التوقيتات، الأنيميشن، الموسيقى، التصدير.
- `tts_offline.py` — الصوت الأوفلاين بالنطق المصري.
- `music.py` — موسيقى ومؤثرات صوتية متولدة بالكود (من غير حقوق ملكية).
- `assets/` — صور المنتج بعد فصلها عن الخلفية وتكبيرها (من صورة المتجر الأصلية `source.png`).
