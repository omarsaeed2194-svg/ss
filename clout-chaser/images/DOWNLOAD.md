# Photo pack: download checklist

All 51 images were generated in the Canva account connected to this project. Canva keeps the full-size files, so they have to be downloaded from there and added to the repo.

## How to add them

1. Open each link below and click **Download**. Pets are cut out, so download them as **PNG** to keep the see-through background. Scenes and portraits can be JPG or PNG.
2. Upload the files to `clout-chaser/images/inbox/` in the GitHub repo (**Add file → Upload files**, then drag them in). Any file names are fine.
3. Tell Claude they're there. Claude matches each photo to its slot by looking at it, then shrinks, compresses and renames it. That's roughly 150 KB per scene, so the app stays small.

If you prefer to sort them yourself, save each one as `images/<folder>/<name>.jpg` (`.png` for pets), using the names in the table, then run `python3 tools/photos.py --optimize`.
